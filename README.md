# Currency Converter Website

The **Currency Converter** is a web-based application that allows users to convert currencies in real-time using live exchange rates fetched from an external API. The project is built using **HTML, CSS, and JavaScript**, providing a simple and user-friendly interface for quick currency conversion.

## 🔹 Features

✅ **Real-Time Currency Conversion** – Fetches the latest exchange rates from an API.  
✅ **User-Friendly Interface** – Simple and intuitive design for quick conversions.  
✅ **API Integration** – Uses a third-party API to provide up-to-date exchange rates.  
✅ **Responsive Design** – Works seamlessly across different devices and screen sizes.  

## 🔹 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **API:** Integrated with a live currency exchange API (e.g., ExchangeRate API, Open Exchange Rates, etc.)  

## 🔹 How It Works

1. The user selects the **base currency** and the **target currency** from dropdown menus.  
2. Enters the **amount** to convert.  
3. The application fetches the **latest exchange rate** via an API call.  
4. The converted amount is displayed instantly.
